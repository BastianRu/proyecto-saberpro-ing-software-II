# Borradores LaTeX — no entregar como SAD

Esta carpeta conserva fuentes `.tex` y PDFs de revisión usados durante la preparación documental. **No son el documento oficial de arquitectura ni el PDF de entrega.**

El SAD que se entrega para la iteración 2 está en `entregables/sprint-2/SAD_Banco_Preguntas_Iteracion2.pdf`, con su fuente editable en la misma carpeta.

Los `.tex` se mantienen como material de apoyo y trazabilidad. Sus PDFs llevan el prefijo `BORRADOR_NO_ENTREGAR` para evitar confundirlos con el SAD oficial.
